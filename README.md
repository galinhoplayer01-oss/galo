# Galo 🐓

Jogo do galo (jogo da velha) para dois jogadores, feito em HTML, CSS e JavaScript.

## Como jogar

- Dois jogadores alternam entre **X** e **O**.
- Ganha quem alinhar três símbolos na horizontal, vertical ou diagonal.
- Se o tabuleiro encher sem vencedor, é empate.
